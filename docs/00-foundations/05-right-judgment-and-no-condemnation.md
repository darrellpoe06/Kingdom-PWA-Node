# Right Judgment and No Condemnation

Built on Romans 8:1, John 7:24, and the Greek distinction between krinō (discernment) and katakrinō (condemnation). The four-section diagnostic structure required for every system output: DATA (descriptive) → TRUTH (Scripture as mirror) → IDENTITY (anchored in Christ, never omitted) → INVITATION (Holy Spirit's work, not the system's).
