## Context
Darrell: "eventually we will want the websites updated by the LLMs." This escalates the LLM from read-only review to WRITE on public surfaces — the highest-risk action class.

## Decision
LLM-authored public/church content is a **deliberately later (Phase N+) capability, not the MVP.** Staged path: read-only review → draft-PR/draft-content (human merges) → scoped auto-publish of low-sensitivity surfaces behind approval → **never** fully-autonomous doctrinal or clinical publish (permanent ceiling). Doctrinal/church + clinical/TLC content is always human-approved; PoeTech marketing copy is the only tier eligible for scoped auto-publish once proven.

## Rationale
Because a wrong publish is public, and for the church it is doctrinal. Earn the write capability per surface as the Cage proves safe; the sensitive entities never leave human-gated publish.

## Consequences
Dependency: a content-approval workflow must exist first. First-pass timeline 2027+. [DR-0007] (calendars) is the first concrete instance of the approval pipeline, de-risking this on a bounded surface.
