## The catch that shaped this decision (premise-verify is not optional)

The orchestration briefing — produced by an outside model wearing another project's framing — asserted an "existing `llm-worker.js`," a Next.js architecture, WebLLM/Edge-AI, and "Project SHALOM." Verified against the repo: `llm-worker.js` exists only in the dead vanilla-PWA scaffold the hardening plan lists for archive; the app is Vite + React; the rest is not ours at all. Had the briefing been built on as written, the work would have stood on fiction. **Hand-carried output from any outside model is premise-verified against the repo before anything is built on it** — now a structural intake step, not a session's alertness.

## Decision

1. **The sourcing bench is Ari's routing knowledge, honestly limited.** One source (`SOURCING_BENCH` in `lib/research-intake.js`) names every instrument the TEAM holds — Darrell (the Governor, and the hand that fires the consumer tools), Claude Code (build/verify/ship), **Gemini Pro + NotebookLM** (native video ingestion, source curation, studio outputs, sandboxed code execution — skills the house verifiably lacks), **ChatGPT** (second-opinion reasoning, images), the NAS lanes (n8n/Whisper/Ollama), and the GitHub runners (the outside-in eyes). Every entry carries its real constraint: **the consumer Gemini and ChatGPT subscriptions have no API** — their output enters hand-carried through the intake, never as an automated dependency; no integration is painted that does not exist.
2. **The intake is the worked pattern, made structural.** Capture whole → **premise-verify** (the catch above) → **house-first** (what do our own Ways, documentation, and LESSONS-LEARNED already hold? a capability we already run is reused, not replaced — and **recorded experience is SENIOR**: a finding that contradicts a standing decision or the Governor's recorded experience is declined by default, reopened only when Ari brings a justified case to governance on real tests and outcomes) → tier (DR-0100) → **evidence-based verdict** (adopted only on a measured result from real use here — *"test and see, not agree without testing... not change just because"*; declines and deferrals carry re-review dates) → one source → recorded (DR + REV + session note) → Ari's duties and reports updated the same session → opportunities dated into the backlog the app sorts.

**The seniority rule proved itself inside this very pass:** the ecosystem scan staged the n8n AI Agent node as "highest-leverage" on adoption signal — and the house record had already judged it: DR-0132 took n8n off every reliability-critical path (the HTTP 530 night; silent Code-node failures; "Succeeded" ≠ correct; LESSONS P17–P19; DR-0083 before it), and Darrell confirmed from experience the same day. The finding is **declined** with the reopen path recorded (a governance case on tests and outcomes only, `re-review: 2026-10-08`), a pinned test holds that nothing recommends n8n back onto the critical path, and the sovereign lane on the bench is the **Supabase-bus + self-orchestrating box** DR-0132 built. Popularity elsewhere is not evidence here.
3. **The Research Day is weekly and MEASURED, never promised.** A research pass on upgrades/features (GitHub ecosystem, skills/MCP, sovereign tooling) is real only when its REV record carrying the `Research Day` marker is filed in `docs/reviews/REVIEWS.md` — the same registry the app parses every build. `researchCadence` derives last-pass / next-due / overdue from those records; **no pass on file reads OVERDUE, never fresh** (the DR-0125 posture applied to research). REV-0033 is the first pass on record.
4. **The timer ships staged, not armed (three brakes).** A weekly Routine (fresh session per fire, Mondays) is configured with its brakes — a one-session budget, a skip-if-prior-run-open lock, and stop-on-repeated-failure — and left **disabled**. Timer-driven Claude compute never self-activates unattended (the 2026-06-06 incident rule); Darrell arms it with a word when he wants the cadence automated. Until then the cadence readout keeps the duty visible and overdue honest.
5. **Ari carries the sourcing duty.** The standing duty resolves against this DR live; the derived notes pick this DR up this build; the bench, the findings, and the cadence render in Ari's record on the Discussions surface — inside the app, derived, no static paint.
