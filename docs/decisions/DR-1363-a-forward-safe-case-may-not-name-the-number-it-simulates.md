## Context

DR-1316's repair pattern is a "forward-safe" case: append the next lesson's number to the course's own list and assert contiguity still holds. The case is right. The way it keeps being written is not — it names the number.

## What was measured

**Three occurrences, the last two inside fixes for the first.**

1. pm13's forward-safety case appended the **literal 14**. True while the course ended at 13.
2. pm14 repaired that one with the derived `PROJECT_MANAGEMENT_MODULES.length + 1` — and then hardcoded **15** in its own case, at `project-management-pm14-verses.test.js:198`.
3. pm15 landed today and **#2567 went red on that literal**: the list became `[1..15, 15]`, contiguity failed, and a lesson was blocked by the gate of the lesson before it. Measured as-is: pm14 **42/43**. Derived: pm13 + pm14 + pm15 **129/129** together.

**The fault is structural, not careless.** A literal is true the day it is written and false on exactly the day the case exists to cover. That is a check that cannot catch what it is for.

## Impact

The cost was never the one-line edit; it was that each recurrence invalidated a verified tree and blocked a merge. Three sessions wrote the convention down and the fourth will not read it, which is what a gate is for.

## Decision

**1. A guard reads it, not a session's memory.** `forward-safe-gate-guard.mjs` fails the build on a line that spreads a course's own `*MODULES` list through `.map(` and then appends a bare integer. Every derived form passes, because none of them names a number. It runs in `ci.yml` beside the other bloat ratchets and in `verify:gates`, because a guard CI never runs is not a guard (DR-0076 §3) — `verify-covers-ci-guards.test.js` refuses it otherwise.

**2. It reads code, not prose, and not a quotation of code.** Whole-line comments are blanked, and so are the contents of quoted strings. That is paid for twice: a scanner of mine matched the word "trash" inside a workflow's own comment promising it never trashes anything, and this guard's first run flagged **four of its own fixtures** — the cases that prove it works, reported as the thing it forbids.

**3. pm14's literal is corrected in place** to the derived form pm15's gate already used, so pm16 owes that file no edit.
