## The discipline (binding for every future Layer 0 edit)

1. **Fold only what is verifiably archived.** A section may fold to its binding FACT + DR pointer only after verifying the DR file carries the section's full substance (measured, not assumed — DR-0076).

3. **The binding fact stays in Layer 0.** A fold never reduces a section to a bare link — the rule itself, stated completely enough to act on, remains; the DR carries the trigger quotes, the enumerated procedure, and the pairing lattice.
4. **Guards prove the fold safe.** The ways/ari-guard/cadence/context-hygiene suites run green before the fold ships (the stop-hook and charter generator are unaffected: consumers cite CLAUDE.md as a source label, verified this pass).
