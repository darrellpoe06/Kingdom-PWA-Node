# DR-0126 — Learn carries the Eternal Algorithms as practical processing courses — derived from the catalog, multi-level, self-paced

- **Status:** accepted
- **Tier:** B (new derived courses on the existing Learn engine; rides the lane)
- **Scope:** Church → Learn; the Godhead-Study catalog as a course source; the multi-level lesson contract; the Scripture study's level switch
- **Date:** 2026-07-08
- **Principles:** WORD-FIRST, APP-IS-PRIMARY, VERIFICATION-DOCTRINE, PERPETUAL-IMPROVEMENT, ANXIETY-CLARITY, DECISION-RECORDS

## Directive

Darrell, 2026-07-08, holding the Learn tab, the Godhead-Study catalog, and the witness rooms: *"The learn tab needs to have all of these courses added as practical learning opportunities — a time to deeply process these concepts from Yahweh."* And, with the Scripture study's 20 themes: *"These 20 lessons also need to be multi neurological level like the others."*

## Decision

1. **Six derived processing courses join Church → Learn** — one per Godhead-Study section (Torah & History 10 patterns, Wisdom & Psalms 17, the Prophets 13, the Gospels 26, the Epistles 32, Revelation 6 — 104 sessions total), every session DERIVED from the same catalog the Eternal Algorithms study renders (`lib/eternal-algorithms-course.js` ← `godhead-study.js`). A pattern added to the catalog joins its course on the next build; nothing is re-typed (DR-0121). Self-paced, one pattern at a time; the in-app practice takes each conditional to the Eternal Algorithms study, then to the learner's Study/Council Chamber for honest processing.
2. **Every session is multi-neurological-level by DEPTH SELECTION** over the catalog's own sentences (the Learn engine's `levels` contract): teen = the Word's own IF + the win, plain; standard = practice + outcome; senior = the full conditional, consequence, practice, and the why-it-works. The same truth at three depths — never an invented rephrase of doctrine (DR-0076).
3. **The Scripture study's level switch now truly branches.** The 2026-07-08 gap: all 20 themes had full depth tiers, but 12 had NO authored level variants — the child/new-believer/scholar switch silently rendered the standard adult text. `resolveLevel` now derives the missing levels from the theme's own authored tiers (child/new believer ← essential, scholar ← deep), authored variants staying senior, `adaptedFrom` carried so the adaptation is honest. Authoring true per-level variants remains open for the SME lane — `re-review: 2026-07-22`.

- **Opportunity:** the witness rooms (third-witness) and the study seeds can join as further derived courses on the same engine — one projection each. `re-review: 2026-07-22`.
- **Opportunity:** quizzes per pattern (the engine supports them) derived from condition/consequence pairs. `re-review: 2026-07-29`.

- **Constraint (verified):** verse text renders from the app's verified KJV corpus by reference — the derive carries references only, quoting nothing from memory.
