# SKOS Documentation

The architectural foundation for SKOS, organized into seven subfolders.

- [`00-foundations/`](00-foundations/) — The fifteen foundational documents: the biblical, scientific, and historical commitments the whole system rests on.
- [`01-architecture/`](01-architecture/) — The SKOS three-layer architecture and the Siemens DDC metaphor applied to human flourishing.
- [`02-modules/`](02-modules/) — The twelve modules, their status, and dependencies.
- [`03-network-playbook/`](03-network-playbook/) — Phase 0 infrastructure: VLAN isolation, platform host, hardware decommissioning.
- [`04-governance/`](04-governance/) — Entities, HIPAA/BAA compliance, estate planning, trust structure.
- [`05-financial-os/`](05-financial-os/) — MVP-1: the Sovereign Family Financial OS.
- [`06-research-log/`](06-research-log/) — Running log of outside sources for later evaluation against the architecture.

**Naming conventions:** Markdown files use kebab-case (`grace-and-mercy-standard.md`). Ordered documents and folders carry two-digit numeric prefixes (`00-`, `01-`, … `15-`).
