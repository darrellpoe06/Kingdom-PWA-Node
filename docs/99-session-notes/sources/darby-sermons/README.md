# Pastor Stephen Darby — sermon transcripts

Fourteen 2016 Next Chapter Radio broadcasts of Pastor Stephen Darby's sermons, held by the
Internet Archive (uploader `nextchapterradio`), transcribed locally on 2026-11-26 with
faster-whisper `base` (int8). One file per sermon, with `[m:ss]` timestamps and a header that
names the archive.org item, its URL, the date and the model.

These are the primary source for the Prophetic Voices Darby lessons. A machine's hearing is
not the speaker's text: verify a line against the recording at its timestamp before quoting it.
The fifteenth item, the 2017 video `understanding-white-supremacy`, is not yet transcribed.
