## Constraints — what bounds the work

1. **The gates are load-bearing and incident-born** — every ci.yml step has a named incident; the required job name `app — lint + vitest` cannot be renamed without a ruleset change first; the layout probe's selftest must precede the real pass (anti-theater, DR-0076 §3).
2. **Docs are parsed into the build** — `vite.config.js` reads decisions/PRINCIPLES/REVIEWS/governance-queue/n8n-workflows at build time; reformatting breaks the Decisions tab and pinned tests. DR-0011 append-only: renumbering is additive, never a rewrite.
3. **Tests pin internals** — 29 test files import monolith internals; 12 import prefixed course symbols; `client-acquisition.test.js:244` pins the `/n8n/` prefix; content gates require ≥12 courses/≥40 lessons by real render. Consolidations move in lockstep with their tests.
4. **The Funnel is a single point of failure** — both proxies hardcode the Funnel origin; every NAS-backed feature dies together (documented live 530). O1 should thread one configurable origin through the shared helper.
5. **DR-0248 raised the stakes on CI health** — all three stop-paths for the armed NAS fleet route through a PR that must pass CI; a wedged lane is now also a wedged fleet-brake. This argues for the CI-speed items and against adding fragile required checks.
6. **Live money secrets sit in Cloudflare Pages env** — moving checkout/stripe-webhook is the highest-blast-radius change in the repo; sequence last, if ever.
7. **Two sessions share this repo** — PR #1119's branch is in flight; DR/REV number allocation reads live origin/main first (this review allocated REV-0215 after fetch); the fake-boundary detector was rebuilt here per direction because it had not landed from the authoring session.
8. **`lib/`'s 25% comment density is institutional memory, not waste** — provenance comments carry DR numbers, dated incidents, live-schema knowledge that exists nowhere else (`rentals-sync.js:1-27`). Comment lines are not a reduction target.
9. **The chunk-per-build byte-uniqueness (`intro:` banner, DR-0139) is deliberate** — a Cloudflare blob-poisoning countermeasure, not an optimization target.
