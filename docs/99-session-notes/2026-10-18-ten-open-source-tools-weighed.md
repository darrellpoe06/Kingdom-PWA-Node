## How it was measured

- Each repo was shallow-cloned into the session scratchpad at a pinned release and read. Nothing from the repos was run.
- Three readers produced one fact sheet per repo. Five deciding claims were re-checked by hand against the source.
- No Docker daemon runs in this sandbox, and the towers are not reachable from it, so no install was attempted.
