# Featured Series: proposed lesson lists (awaiting Darrell's approval)

Status 2026-11-26. **Proposed, not approved.** Each series is an ordered reading list over lessons that already exist, chosen by reading them and arranged from recognising the need to acting on it. A series only points at lessons: no lesson, title, course or department changes, and a lesson can sit in a series and in its own course at once. The lists live in `app/src/lib/learn-discover-series.js`; a test fails the build if any id stops resolving.

To change a list: strike or reorder rows below (or tell me), and it is a one-line edit. The page marks the section "Proposed lists" until you approve.
